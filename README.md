# Agentic AI Portfolio Web Service

This is a ready-to-deploy Node.js Express web service for the Agentic AI portfolio scenario.

## Run locally

```bash
npm install
npm start
```

Open:

```text
http://localhost:3000
```

## Deploy to Render

Use these settings:

```text
Build Command: npm install
Start Command: npm start
```

## Pages

```text
/              Homepage
/health        Health check API
/api/message   Portfolio API message
```
